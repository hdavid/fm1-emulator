Seventeen Rust integration tests pass. They check malformed ELF handling,
exact ELF-to-bin reconstruction, raw and ELF boot agreement, arithmetic and
branch behavior, real hardware probe words, RAM instruction execution, dirty
BSS initialization, timer wrap/divider phase/acknowledgment/masking, missing
vectors, GPIO electrical gating, and all eleven matrix columns with released,
pressed, and multiple-key inputs. Rust Clippy is also run with warnings denied.

Five of ten equally weighted foundations are exercised: CPU, memory/startup,
timers, interrupts, controls. This is the user-agreed milestone checklist,
not 50% of all CPU instructions or 50% of Felucca's musical functionality.
Flash, LCD, USB serial, USB MIDI, and audio/DMA are not implemented.

The complete FM-1_980 diagnostic image loads and its probe executes unchanged,
but its normal boot still faults on the first unimplemented startup instruction
(0xE160 at 0x02001DB6). Full Felucca boot is not claimed.
Unknown opcodes and MMIO fault explicitly. No firmware functions are replaced
by host functions and no boot instructions are silently skipped.

Peripheral models use existing FM-1 HAL addresses and wiring. Virtual time is
24 oscillator ticks per guest instruction, not measured timing. Interrupt
entry and initial CPU state are functional approximations. Only the original
twelve-word CPU probe has been independently compared with physical hardware;
new timers/interrupts/controls models still require hardware validation.

The physical FM-1 remains on FM-1_980. This integration image has no USB updater
or recovery and is not packaged or offered for installation on the device.
